# Contributing to reyki.me

Thanks for helping! Typo fixes, broken links, bug reports and ideas are all welcome.

## Before you start

- **Bugs and ideas:** open an [issue](https://github.com/bitsandbricks-ch/reyki.me/issues/new/choose)
  first, so we can agree on the approach before you spend time on it.
- **Security problems:** please don't open a public issue. See [SECURITY.md](SECURITY.md).

## Making changes

1. Fork the repo (or make a branch, if you have access) and keep one topic per pull request.
2. Run the checks from [AGENTS.md](AGENTS.md#before-you-push) before you push.
3. Open the pull request as a draft and fill in the template. CI must be green before it can be merged.

This repo follows the [BitsAndBricks handbook](https://github.com/bitsandbricks-ch/handbook).
Coding agents: [AGENTS.md](AGENTS.md) has the rules you follow.
